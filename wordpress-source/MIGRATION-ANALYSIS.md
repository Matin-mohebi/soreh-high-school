## ۲. ساختار قالب Class Stars

| فایل | نقش |
|---|---|
| `front-page.php` | صفحه اصلی: دروازه ورود (دو نیمه)، هیرو، درباره + ۳ آمار، مدیر و معاونان، دانش‌آموزان برتر، دعوت به عضویت |
| `header.php` | نوار بالای چسبان + منو + دکمه‌های ورود/ثبت‌نام |
| `footer.php` | نام بزرگ مدرسه + یادداشت + آدرس + تلفن |
| `functions.php` | ۱۵ فیلد Customizer، دو نوع محتوا (`staff`، `student`)، متاها، فرم‌های ورود/ثبت‌نام با nonce و تله ضد ربات |
| `style.css` | سه لایه CSS: پایه، لایه سه‌بعدی، پرداخت نهایی (رنگ‌های نهایی) |
| `assets/app.js` | دروازه ورود (sessionStorage)، انیمیشن ظهور با اسکرول، شمارنده آمار با ارقام فارسی |
| `page.php` / `single.php` / `index.php` | قالب برگه ساده (ورود/ثبت‌نام) |

### فیلدهای قابل ویرایش (Customizer)
`school_name`, `hero_text`, `hero_image`, `about_title`, `about_text`,
`stat1_n/l`, `stat2_n/l`, `stat3_n/l`, `staff_title`, `staff_text`, `gate_staff_text`,
`students_title`, `students_text`, `gate_students_text`, `address`, `phone`, `note`

### انواع محتوا (CPT)
- **مدیر و معاونان** (`staff`): عنوان، توضیح/چکیده (بیوگرافی)، عکس شاخص، سمت (`cs_role`)، ترتیب
- **دانش‌آموزان برتر** (`student`): عنوان، عکس شاخص، رتبه (`cs_rank`)، پایه (`cs_grade`)، نکته (`cs_note`)، ترتیب
