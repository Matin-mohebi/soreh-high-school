نصب قالب Class Stars
1) وردپرس را روی هاست نصب کنید و زبان را فارسی بگذارید.
2) پیشخوان ← نمایش ← پوسته‌ها ← افزودن ← بارگذاری ← فایل class-stars.zip ← فعال‌سازی.
   (با فعال‌سازی، صفحه‌های «ورود» و «ثبت‌نام» خودکار ساخته می‌شوند.)
3) تنظیمات ← پیوندهای یکتا ← «نام مطلب» را ذخیره کنید.

ویرایش محتوا (فقط مدیر سایت)
- مدیر و معاونان: منوی «مدیر و معاونان» ← افزودن عضو (نام، عکس شاخص، توضیح، سمت). ترتیب از «ویژگی‌های برگه ← ترتیب».
- دانش‌آموزان برتر: منوی «دانش‌آموزان برتر» ← افزودن (نام، عکس شاخص، رتبه، پایه، نکته).
- متن‌ها، آمار، عکس بالای صفحه، آدرس و تلفن: نمایش ← سفارشی‌سازی.
- وقتی با حساب مدیر وارد سایت باشید، کنار هر بخش و هر جای خالی لینک «ویرایش» می‌بینید.
- کاربران ثبت‌نام شده: پیشخوان ← کاربران.
