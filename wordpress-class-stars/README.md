# اطلاعات تماس مدرسه سوره زنجان برای قالب Class Stars

این پوشه افزونه کامل یا قالب مستقل نیست؛ یک بخش آماده برای اضافه‌کردن اطلاعات تماس مدرسه به قالب وردپرس Class Stars است.

## شماره‌های ثبت‌شده

- شعبه پسران: **۰۲۴-۳۳۸۷۶۰۳۰**
- شعبه دختران: **۰۲۴-۳۳۴۲۰۱۹۷**
- تلفن همراه شعبه دختران: **۰۹۰۲۲۴۲۵۴۷۶**
- وب‌سایت رسمی: https://www.sooreh-honar.ir/portal/index.html

## نصب

1. فایل `school-contacts.php` را در پوشه اصلی قالب فعال Class Stars قرار دهید.
2. این خط را در `functions.php` قالب اضافه کنید (اگر قبلاً اضافه نشده است):

   ```php
   require_once get_template_directory() . '/school-contacts.php';
   ```

3. محتوای `contacts.css` را به انتهای `style.css` قالب اضافه کنید یا آن را جداگانه enqueue کنید.
4. برای نمایش کارت تماس در برگه، ابزارک یا بخش پشتیبانی‌شده از شورت‌کد زیر استفاده کنید:

   ```text
   [soreh_school_contacts]
   ```

شماره‌ها به لینک قابل لمس `tel:` تبدیل می‌شوند تا روی گوشی بتوان مستقیماً تماس گرفت.

## نکته مهم

کد کامل قالبی که در پیام ارسال شده بود شامل بخش‌هایی ناقص/به‌هم‌ریخته بود؛ بنابراین این پوشه فقط کد تماس‌ها و استایل آن را به‌صورت فایل‌های قابل استفاده نگه می‌دارد و ادعا نمی‌کند کل قالب Class Stars از روی متن ناقص بازسازی شده است.
