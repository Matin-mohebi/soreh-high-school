# وب‌سایت هنرستان‌های غیردولتی سوره زنجان

وب‌سایت معرفی استاتیک فارسی و راست‌چین برای هنرستان‌های غیردولتی دخترانه و پسرانه سوره زنجان.

## امکانات سایت

- معرفی هنرستان و حوزه‌های آموزشی
- معرفی رشته‌ها و دوره‌های فنی‌وحرفه‌ای
- مشاوره و هدایت تحصیلی و کنکور هنر
- نمایش نمونه‌ای از اخبار، افتخارات و فعالیت‌های هنرجویان
- نشانی و شماره تماس شعبه‌های دختران و پسران
- پیوند به وب‌سایت رسمی مجموعه برای ثبت‌نام، ورود کاربران و خدمات مجازی

## انتشار با GitHub Pages

فایل اصلی سایت در مسیر `site/index.html` قرار دارد و مستقل از سرور، پایگاه داده و پنل مدیریت اجرا می‌شود.

1. در تنظیمات مخزن، بخش **Pages** را باز کنید.
2. بخش انتشار را روی شاخه `static-school-site` و پوشه `/site` تنظیم کنید؛ یا پس از بررسی، این تغییرات را به شاخه‌ای که GitHub Pages از آن منتشر می‌کند منتقل کنید.
3. پس از پایان انتشار، آدرس نمایش‌داده‌شده در بخش Pages را باز کنید.

## خدمات رسمی و اطلاعات

وب‌سایت رسمی مجموعه: https://www.sooreh-honar.ir/portal/index.html

پیوندهای ثبت‌نام و ورود کاربران در این نسخه به وب‌سایت رسمی مجموعه هدایت می‌شوند؛ این پروژه فرم ورود یا پنل مدیریت مستقل ندارد.

## نکته درباره اطلاعات

رشته‌ها، خبرها و اطلاعات تماس در صفحه معرفی بر اساس محتوایی تنظیم شده‌اند که برای پروژه فراهم شده است. برای تأیید ظرفیت رشته‌ها، شرایط ثبت‌نام، برنامه‌ها و اطلاعات به‌روز، وب‌سایت رسمی مجموعه را بررسی کنید.
